# Obsidian artwork

The purple logo comes from the [Obsidian brand assets](https://obsidian.md/brand).
The app icon source is the default SVG from [The new Obsidian icon](https://obsidian.md/blog/new-obsidian-icon/).

- `obsidian-icon.svg` is the source for the macOS AppIcon PNGs.
- The unchanged gradient logo is stored in `MarkdownEditor/Assets.xcassets/ObsidianLogo.imageset` and used on the welcome screen and in the vault sidebar.
- The app icon uses the same 3/32 inset as Obsidian's macOS icon export.

Regenerate the icon PNGs with `swift scripts/generate_app_icon.swift` on macOS.

The Obsidian name, logo, and app icon belong to Obsidian. See the linked brand guidelines for usage terms.
